# Задание 4 (контрольное). Вёрстка макета `02.psd`

## Состав папки

| Путь | Назначение |
|------|-----------|
| `index.html` | свёрстанная страница (адаптивная, подключает `css/styles.css` и — в явном виде — фреймворк LESS: `less/styles.less` + клиентский компилятор `js/less.min.js`) |
| `less/_variables.less` | дизайн-токены: цвета, шрифты, размеры контейнера |
| `less/_mixins.less` | примеси `.container()`, `.section-head()`, `.divider()` |
| `less/_base.less` | базовые (десктопные) стили — вся раскладка на flexbox |
| `less/_adaptive.less` | медиазапросы 1024px и 640px |
| `less/styles.less` | входной файл адаптивной версии |
| `less/styles-desktop.less` | входной файл только десктопной версии (для задания 6) |
| `css/styles.css` | скомпилированная адаптивная версия (22 КБ) |
| `css/styles-desktop.css` | скомпилированная десктопная версия (18 КБ) |
| `img/` | 38 ассетов, извлечённых из PSD (JPG/PNG, всего ~554 КБ) |
| `js/less.min.js` | клиентский компилятор LESS (v4.2.x, локальная копия из npm-пакета `less`) |
| `package.json` | манифест: зависимость `less`, скрипты пересборки `npm run build` / `npm run build:desktop` |
| `val-html.json`, `val-css.json` | результаты W3C-валидации (см. ниже) |

Компиляция: `npx lessc less/styles.less css/styles.css` (использован npm-пакет `less`).

## Явное подключение фреймворка LESS

В `<head>` страницы фреймворк LESS подключён в явном виде:

```html
<link rel="stylesheet" href="css/styles.css">
<link rel="stylesheet/less" type="text/css" href="less/styles.less">
<script src="js/less.min.js"></script>
```

- `less/styles.less` — исходники LESS (переменные, миксины, вложенность, медиазапросы), компилируются прямо в браузере локальным `less.min.js` (работает офлайн, сервер не нужен).
- `css/styles.css` — заранее скомпилированный тем же исходником результат (`npm run build`).
- Результат компиляции совпадает с `css/styles.css`, поэтому стили применяются корректно в обоих режимах; продублированные одинаковые правила на отображение не влияют.
- Для проверки чистой LESS-компиляции достаточно закомментировать строку `<link rel="stylesheet" href="css/styles.css">`.

## Flexbox

Вся раскладка — flexbox, без float/grid:
- `.header__row`, `.facts__row`, `.about__gallery`, `.services__grid`,
  `.wedo__row`, `.quote__row`, `.team__grid`, `.works__gallery`,
  `.say__grid`, `.blog__grid`, `.footer__grid`, `.subscribe`,
  `.accordion__head` — flex-контейнеры;
- выравнивание колонок галереи работ одинаковой высоты — `.works__col { flex: 1;
  display: flex; flex-direction: column }` + `.work { flex: 1 }`;
- `justify-content: space-between` для колонок по макету, `align-items` для
  вертикального выравнивания.

## Адаптивность (контрольные точки 1024px / 640px)

- ≤1024px: тройные сетки → 2 колонки (`flex-wrap` + `flex-basis: 46%`); факты
  5→3+2; «What we do» в столбец; галерея работ 4→2 колонки; подвал в 2 колонки;
  шапка с переносом.
- ≤640px: все сетки в 1 колонку; факты 2+2+1; меню по центру, декоративные
  иконки скрыты; стрелки цитаты повёрнуты вертикально; подписка в столбик.

## Валидация W3C

- **HTML** — валидатор <https://validator.w3.org/nu/> (движок Nu, тот же, что на
  validator.w3.org): **0 ошибок** (`val-html.json`). Найденные при проверке 2
  ошибки (`figcaption` внутри `blockquote`) исправлены переносом `figcaption`
  на уровень `figure`.
- **CSS** — валидатор <https://jigsaw.w3.org/css-validator/>, профиль CSS3:
  **0 ошибок** в обеих компиляциях (`val-css.json`). Т.к. прямой POST-интерфейс
  jigsaw сейчас отвечает HTTP 500, файл валидировался пофрагментно GET-запросами
  по границам верхнеуровневых правил (4 чанка для адаптивной, 3 для десктопной);
  все чанки валидны. Дополнительно обе компиляции целиком проверены валидатором
  Nu с `Content-Type: text/css` — 0 ошибок.

## Особенности реализации

- Тексты макета — латинский болваночный (Lorem ipsum, как в PSD), названия
  секций/имена сохранены как в макете.
- Шрифты подключены с Google Fonts с `preconnect` (Montserrat 400/700, Kaushan
  Script, Roboto 400/300i) — те же гарнитуры, что в слоях PSD.
- Hover-эффекты карточек: градиентный оверлей `#F38181→#FCE38A` (из макета),
  сдвиг фото `translate(10px,-10px)` с мятной подложкой.
- Accordion «What we do» свёрстан на нативных `<details>/<summary>` — работает
  без JavaScript; стрелка поворачивается селектором `[open]`.
- Форма подписки: скрытая `label` (доступность), `type="email"`, `required`.
- Кнопки-стрелки цитаты — `<button type="button">` с `aria-label`.
- Все `<img>` имеют осмысленные `alt`, `width`/`height` (нет CLS).
- Пустые ссылки соцсетей — `href="#"` (учебный макет).
